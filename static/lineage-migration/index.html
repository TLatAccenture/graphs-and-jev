        How to read the result
        
        
        
          
        Proceed
        Lineage supports it. It runs, with the blast radius attached.
        
          
        Ask
        A detail is missing or ambiguous. The agent asks.
        
          
        Escalate
        A fact, such as an owner, is missing. A person decides.
        
          
        Refuse
        Unsafe or out of scope. Stops before any tool call.
        
          
        No data
        The object is not in the lineage graph.
